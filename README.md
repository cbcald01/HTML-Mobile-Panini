# Mobile Panini Website

**CIS 150 - Project 1**

## Project Overview
Created a multi-page website for Mobile Panini, a fictional Italian food truck, as part of a web development assignment. The website introduces the business and provides navigation to its menu, events, and catering pages.

## Features
- Includes Home, Menu, Events, and Catering pages.
- Uses a navigation menu to link between pages.
- Applies CSS styles for the website's layout and appearance.
- Displays business images and contact information.

## Skills Demonstrated
HTML · CSS · Web Development
